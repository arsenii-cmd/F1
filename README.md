# F1 GRID

Приложение о Формуле 1 на GitHub Pages: календарь, результаты гонок и спринтов, личный зачёт, Кубок конструкторов, трансляции и новости.

## Два оформления

Переключатель «Старый вид / Новый вид» сохраняет выбор на устройстве. По умолчанию открывается F1 GRID: ночной паддок, оранжевый болид, стеклянные панели, обратный отсчёт, поиск и фильтры календаря, карточки лидеров и интерактивная трасса.

В обоих видах работают одна загрузка данных и один набор таблиц. Выбранный сезон и текущая вкладка сохраняются при переключении оформления. Исходный `styles.css` оставлен без изменений; `script.js` сохранён для совместимости с уже закэшированной старой страницей.

## Запуск

Сборка и npm не нужны:

```sh
python -m http.server 4173
```

Открыть `http://localhost:4173`. GitHub Pages публикует корень репозитория. Все основные шрифты и графика локальные; лицензии шрифтов лежат в `assets`.

## Данные и новости

- `season-data.js` — настройки и исходные резервные данные сезонов 2023–2026.
- `core.js` — Jolpica, кэш данных, защита от устаревших ответов при смене сезона, гонки/спринты и модальное окно.
- `modern.css` / `modern.js` — новый вид, фильтры, карточки, новости и анимации.
- `data/news.json` — настоящие заголовки RSS с источником, датой и ссылкой на публикацию. Тексты статей не копируются.
- `scripts/refresh_news.py` и `.github/workflows/news.yml` обновляют ленту раз в шесть часов, сохраняют предыдущую при сбое всех источников и запрашивают повторную сборку GitHub Pages. Доступен ручной запуск workflow.
- `sw.js` / `pwa.js` — автономная оболочка и обновление установленного приложения. Кэш изолирован от других приложений на том же домене.

Резервные спортивные данные помечаются как устаревшие. Новости при отсутствии сети показывают сохранённую ленту с датой обновления. Движение учитывает системную настройку уменьшения анимации; ночной заезд можно отдельно запустить, остановить и ускорить.

## Проверка интерфейса

`tests/ui_check.py` проверяет оба вида, сохранение переключателя, все зачёты, гонки и спринты, восстановление действий из кэша, сезоны, поиск, фильтры, новости, анимацию и размеры 360/390/768/1440 px. Для теста используются отдельные предсказуемые ответы API; в приложение они не попадают.

```sh
pip install playwright
playwright install chromium
python -m http.server 4173
# В другом терминале:
python tests/ui_check.py
```

Опционально: `F1_TEST_BASE` — адрес тестового сервера, `F1_CHROMIUM` — путь к Chromium, `F1_TEST_ARTIFACTS` — папка скриншотов.
