# F1 — Визуализация

Приложение о Формуле 1: календарь, результаты гонок и спринтов, личный зачёт, Кубок конструкторов, трансляции и новости. Работает как PWA, сборка не нужна.

## Три варианта сайта

В правом нижнем углу есть переключатель **«Старый / Codex / Claude»**. Выбор хранится на устройстве (`localStorage`, ключ `f1_variant`), выбранный сезон общий для всех вариантов.

- **Старый**: исходный интерфейс (`styles.css`, `script.js`) на главной странице.
- **Codex** — «F1 GRID» из ветки `feature/f1-grid`, лежит отдельной страницей в `codex/` (`codex/core.js`, `codex/modern.js`, `codex/modern.css`, `codex/assets/`). Если выбран этот вариант, главная страница сразу открывает `codex/`.
- **Claude** — «F1 APEX» (`claude.css`, `claude.js`), открывается по умолчанию:
  - первый экран со стартовыми огнями и болидом, который срывается с места, когда огни гаснут;
  - обратный отсчёт и расписание уикенда, прогресс сезона, лидер чемпионата;
  - календарь с фильтрами и поиском, окно результатов гонки и спринта;
  - личный и командный зачёт, «Ночной заезд» пятёрки лидеров, новости, трансляции.

  Используются «жидкое стекло» (`backdrop-filter`, SVG-фильтр преломления), `@property`, scroll-driven анимации, View Transitions, container queries, `:has()`.

Переключатель (`switch.css`, `switch.js`) общий для обеих страниц. Сервис-воркер `sw.js` лежит в корне и обслуживает все варианты.

## Данные

- Спорт: [Jolpica / Ergast API](https://github.com/jolpica/jolpica-f1). Если API недоступен, показываются резервные данные из `script.js`, а над разделами появляется пометка об этом.
- Новости: `data/news.json`. Это только заголовки, ссылки на источник, даты и превью из RSS F1News, Motorsport и Autosport, тексты статей не копируются. Ленту обновляет `scripts/fetch_news.py`: его запускает workflow `.github/workflows/news.yml` каждые 4 часа, вручную — через *Run workflow*. Расписание GitHub Actions срабатывает только в ветке по умолчанию.

## Запуск

```sh
python -m http.server 4173
# открыть http://localhost:4173
```

## Проверка интерфейса

`tests/ui_check.py` проверяет три варианта и переключатель, данные, фильтры, поиск, окно результатов, смену сезона, ширины 360–1440 px, режим уменьшенного движения и резервные данные без API. Ответы API в тесте подменяются.

```sh
pip install playwright && python -m playwright install chromium
python -m http.server 4173
python tests/ui_check.py   # в другом терминале
```
